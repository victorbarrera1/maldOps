## QUE ES MALDOPS?

> **MALDOPS es una plataforma web que permite gestionar campañas publicitarias. Su enfoque es en el marketing digital, para poder optimizar y gestionar campañas publicitarias en diferentes plataformas. Hoy en dia existen muchas agencias de marketing digital que ofrecen este servicio, pero MALDOPS busca ser una alternativa mas accesible y eficiente para los usuarios. De manera que contiene todos los servicios actuales de publicidad en internet, algunos de los mas populares son: Meta Ads (Facebook e Instagram), Google Ads (Youtube, Google Search), TikTok Ads, Twitter Ads, LinkedIn Ads, etc. Ademas de tener herramientas para poder analizar el rendimiento de las campañas y optimizarlas.

## COMO INGRESAR LOCALMENTE A MALDOPS
1. Instalar los archivos del repositorio, ya sea via bash o descargandolo como zip directamente
2. Ingresar a la carpeta desde la terminal (cd /Users/***/Maldoops)
3. Ejecutar el comando 'npm run dev'
4. Abrir el navegador y ejecutar la pagina en localhost:3000 (o el que se haya designado)
5. Ingresar las credenciales (usuario/contraseña)
6. Una vez dentro, se puede comenzar a utilizar la pagina.
